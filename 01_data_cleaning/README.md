# 📊 Data Cleaning - Processamento e Limpeza de Dados
## Sobre Esta Pasta
Esta pasta contém projetos especializados em limpeza e processamento de dados, focados em transformar dados brutos, inconsistentes ou problemáticos em bases estruturadas e confiáveis para análise.

## Objetivo Geral
Fornecer soluções reprodutíveis e automatizadas para problemas comuns de qualidade de dados, garantindo que as informações estejam:

✅ Consistentes: Padrões uniformes em todas as entradas
✅ Precisas: Dados corretos e livres de erros
✅ Completas: Sem valores faltantes críticos
✅ Válidas: Dentro dos domínios esperados
✅ Prontas para análise: Formatos adequados para ferramentas de BI/ML

## Tecnologias e Ferramentas Comuns
- Linguagens:
Python (pandas, numpy, regex)
SQL para transformações em banco
Bash para automação de pipelines

- Bibliotecas Python:
pandas → Manipulação de dados
numpy → Operações numéricas
re → Expressões regulares
datetime → Manipulação de datas
fuzzywuzzy → Matching aproximado
great-expectations → Validação de dados

- Ferramentas de Qualidade:
Validação: Great Expectations, Deequ
Versionamento: DVC (Data Version Control)
Orquestração: Apache Airflow, Prefect
Documentação: Data dictionaries, data catalogs

- Checklist de Qualidade:
Consistência: Mesmo padrão em todos os registros
Integridade: Chaves primárias únicas, referências válidas
Acurácia: Dados corretos e atualizados
Completude: Valores não nulos onde necessário
Validade: Dentro de domínios e regras de negócio
Temporalidade: Datas coerentes e sequenciais
