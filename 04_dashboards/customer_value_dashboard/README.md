# Projeto de Dashboard (Customer Value)
## 🎯 Objetivo do projeto

Transformar os resultados do modelo de Machine Learning em um dashboard analítico e decisório, focado em segmentação de clientes e valor para o negócio.

### Contexto de Negócios

Instituições financeiras frequentemente gerenciam grandes carteiras de clientes com diferentes níveis de engajamento e rentabilidade. Identificar clientes de alto valor e compreender seus padrões de comportamento é essencial para aprimorar estratégias de retenção e otimizar os esforços de marketing.

Este painel foi desenvolvido para fornecer uma visão orientada a negócios da segmentação de clientes com base no comportamento de transação e em métricas de engajamento.

### Questões de Negócios

1. Como os clientes estão distribuídos entre os segmentos de valor?
2. Quais padrões de comportamento diferenciam os clientes de alto valor?
3. Quais segmentos de clientes apresentam maior risco de inatividade?
4. Quais características financeiras definem cada segmento?

### Público-alvo

- Equipes de marketing
- Equipes de CRM e relacionamento com o cliente
- Equipes de estratégia de negócios e análise de dados
